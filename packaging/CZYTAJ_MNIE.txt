VidSum — analiza filmów (mowa + obraz)
=======================================

START
  Kliknij dwukrotnie „VidSum Start” (VidSum Start.exe albo VidSum Start.cmd).
  Program działa W TLE — bez czarnego okna — i otwiera stronę w przeglądarce.
  Wyłączasz go przyciskiem „Zakończ” w prawym górnym rogu strony.
  Ponowne kliknięcie „VidSum Start”, gdy program już działa, tylko otwiera stronę.
  Dziennik (gdyby coś nie działało): %LOCALAPPDATA%\VidSum\vidsum.log

WYMAGANE OSOBNO
  Ollama + model obrazu (jednorazowo, w PowerShell):
      winget install Ollama.Ollama
      ollama pull qwen3-vl:4b-instruct

SZYBCIEJ (zalecane, jednorazowo w PowerShell, potem Ollama: ikona lamy → Quit i uruchomić ponownie):
      setx OLLAMA_NUM_PARALLEL 3
      setx OLLAMA_FLASH_ATTENTION 1
  Ollama liczy wtedy kilka zapytań naraz (tłumaczenie razem ze streszczeniem, części streszczenia naraz).

OPCJONALNIE
  Program streszcza sam (lokalny model). Claude to dodatek: Claude Code zalogowany kontem Pro
  i w Ustawieniach streszczenie = claude, albo przycisk „Kopiuj prompt dla Claude”.

PIERWSZE URUCHOMIENIE
  Program pobierze (jednorazowo): model mowy Whisper (~1,6 GB), model tekstowy gemma3:4b do Ollamy (~2,5 GB)
  i — jeśli masz kartę NVIDIA — biblioteki CUDA (~1,3 GB) do %LOCALAPPDATA%\VidSum.
  Wyniki trafiają do Dokumenty\VidSum (zmienisz w Ustawieniach).

WIERSZ POLECEŃ
  VidSum.exe "C:\ścieżka\film.mp4"
  VidSum.exe "https://www.youtube.com/watch?v=..."
  VidSum.exe --help

Windows SmartScreen może ostrzec, że program jest nieznany (nie jest podpisany certyfikatem).
Kliknij „Więcej informacji” → „Uruchom mimo to”.
